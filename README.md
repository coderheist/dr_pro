🚗 Project Overview (Crisp Version)

This project implements an end-to-end autonomous driving system that predicts steering angles directly from front-facing camera images. The pipeline includes data collection, preprocessing, augmentation, a CNN model inspired by NVIDIA’s self-driving architecture, and real-time deployment via a Flask server. The trained model connects to the Udacity Self-Driving Car Simulator, processing live camera frames and returning steering predictions to autonomously navigate the track.
